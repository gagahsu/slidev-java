## 5-1 if 敘述：三種形式

好，先從 `if` 開始。

你可以把 `if` 想成生活裡的「如果」。你問自己：「今天要不要加班？」

第一種，**單純 if**：如果老闆叫你加班，就加班。沒叫？那就滾回家。

第二種，**if-else**：二選一。加班就待下來，不加班就跑路——這叫「二擇一」。

第三種，**if-else if-else 鏈**：這個就比較複雜了，就像你在夜市選吃的：「雞排？賣完了。珍奶？排太長。臭豆腐？好，就你了。」一個一個條件往下試，第一個符合的就執行，後面全部跳過。

這裡有個超重要的細節：**鏈裡只要有一個 case 成立，後面再怎麼符合也不管了**。所以條件的順序很重要，後面我們會看到這一點。

---

## if 與 if-else 語法範例

來看程式碼。這個 `score = 85`，你要判斷他及不及格。

單純 `if`：`if (score >= 60)`，如果分數大於等於 60，就印「及格」。如果不符合？程式啥也不做，直接跳過去。就像你問朋友：「你及格了嗎？」他沈默——那就是沒及格，但他也不想說。

加上 `else` 之後，情況就不一樣了：及格印「及格」，不及格印「不及格」——明明白白，兩條路都走到。

這個結構超常用，幾乎每個 Java 程式都會有。先把它練熟。

---

## if-else if-else 鏈範例

好，再來一個更複雜的例子——成績分等級。

`score = 72`。程式從上到下依序問：「有沒有 90 分以上？沒有。有沒有 80 分以上？沒有。有沒有 60 分以上？有！」好，印「及格」，然後離開，下面兩個條件完全不看。

注意這裡有個設計原則：**條件要從最嚴格到最寬鬆排**。如果你把 `>= 60` 放第一個，那全部及格的人都被攔在那裡，後面 `>= 80`、`>= 90` 永遠輪不到——你的優秀同學會氣得要命。

記住：由嚴到寬，不要讓寬鬆條件「搶跑」。

---

## 三元運算子 `? :`

好，接下來介紹一個很帥氣但容易被誤用的語法——**三元運算子**。

格式是：`條件 ? 值A : 值B`。

就是說：「如果條件是真的，我要值A；否則給我值B。」

例子：找兩個數誰比較大，`int max = (a > b) ? a : b;`——一行搞定，直接賦值給 `max`。這如果用 if-else 寫，至少要四行。

三元運算子還可以巢狀，但我**誠心建議**：超過兩層巢狀就不要用了。你寫完三層巢狀，過兩週回來看，你自己也看不懂——然後你會恨自己。

---

## 三元運算子 vs if-else：什麼時候用什麼？

來做個對比。

三元運算子：一行、可以直接賦值給變數、簡短條件很漂亮。

if-else：多行、適合複雜邏輯、步驟多的時候更清晰。

**使用原則很簡單**：邏輯簡單、一句話說得清楚，就用三元；邏輯複雜、要做好幾件事，就乖乖用 if-else。

別為了「看起來很厲害」就把所有東西都塞進三元運算子。可讀性比炫技更重要——你的同事、你未來的自己，都會感謝你。

## 5-2 switch 敘述：傳統語法

進入第二部分，`switch` 登場！

如果說 `if-else if` 鏈是夜市一攤一攤逛，那 `switch` 就是你直接走到正確的攤位。

傳統 `switch` 的結構：你給它一個值，它直接跳到對應的 `case`。

幾個重點：
- `switch` 裡的變數型別可以是整數、字元、字串、enum——但**不能是 double 或 float**（浮點數你拿來 switch，精度問題會讓你哭）。
- `case` 後面用冒號 `:`。
- `break` 很重要，不加的話程式會「貫穿」到下一個 case——這個等一下說。
- `default` 是選填的，就像「以上皆非」的選項。

---

## Fall-through 效果

好，說一個很多新手踩過的坑——**fall-through（貫穿效果）**。

不加 `break` 的時候，程式執行完一個 case 之後，會繼續往下跑，直到遇到 `break` 或 switch 結束。

聽起來很恐怖對吧？其實這個特性**可以善用**。看這個例子：你要判斷是工作日還是假日。星期一到五都是工作日，你不用寫五個 case 加五個 break——你讓 case 1 貫穿到 case 2、case 3……一直到 case 5，最後統一接一個 `println("工作日")` 加 `break`。

這是一個刻意設計的 fall-through，很優雅。但如果是不小心忘記 `break`，那就是 bug——所以記得，**有意為之才叫技巧，不小心才叫失誤**。

---

## switch 搭配字串

Java 7 開始，`switch` 支援字串！

這個超實用。你可以根據「春」「夏」「秋」「冬」這種文字直接做判斷，不用再把季節轉成數字。

但有一個要注意的坑：**字串比較是大小寫敏感的**。「春」跟「春 」（多一個空格）就不一樣了——更不用說「Spring」跟「spring」。

如果輸入是來自使用者，建議先統一格式：`.toLowerCase()` 全轉小寫，或 `.toUpperCase()` 全轉大寫，再丟進 switch。不然你的程式很可能在 demo 的時候，因為使用者多打了一個大寫字母就爆炸——就在你老闆面前。

---

## Java 14+ Switch Expression：語法對比

好，現在我們來看新時代的 switch——**Switch Expression**，Java 14 推出，超好用。

跟傳統 switch 比，有幾個大差異：

1. 用**箭頭** `->` 取代冒號 `:`，**不需要 break**——fall-through 的問題直接消失！
2. **可以直接賦值給變數**——`String result = switch (x) { ... };`，一行搞定。
3. 多個值可以用**逗號分隔**：`case A, B, C ->`，超簡潔。
4. 編譯器會要求你**涵蓋所有可能值**——再也不會因為漏掉某個情況而藏 bug。

說真的，我第一次看到這個語法的時候，有一種「Java 終於長大了」的感覺。

---

## Switch Expression 基本用法

來看範例，非常直覺。

`int day = 3`，然後：

```
String dayName = switch (day) {
    case 1 -> "星期一";
    ...
    default -> "假日";
};
```

就這樣。不用 break，不用擔心貫穿，直接把結果指派給 `dayName`。

`day = 3` 就回傳 "星期三"，印出來。清清楚楚，一目了然。

這個語法我強烈建議你以後寫 switch 都用這個——除非你有特殊理由需要 fall-through，才回去用傳統寫法。

---

## Switch Expression：多值 case 與 yield

再看一個更進階的例子——計算每個月有幾天。

一月、三月、五月……這幾個月全部都是 31 天，你可以一行搞定：`case 1, 3, 5, 7, 8, 10, 12 -> 31;`

四月、六月、九月、十一月：`case 4, 6, 9, 11 -> 30;`

然後二月呢？二月比較麻煩，要判斷閏年，需要多行邏輯。這時候就用**大括號 + `yield`**——`yield` 的功能就像 `return`，但它是專門給 switch expression 用的。

`yield leap ? 29 : 28;`——結合三元運算子，一行把閏年非閏年都處理掉。

---

## Java 17 Pattern Matching for switch

好，接下來是壓軸——**Java 17 的 Pattern Matching for switch**。

你有沒有想過，如果傳進來的不是一個固定的值，而是**不知道型別的物件**呢？以前你要先用 `instanceof` 判斷型別，再 cast，很囉嗦。

Java 17 說：「我來幫你。」

新語法讓你在 case 裡面**直接比對型別，並自動綁定變數**：
- `case Integer i ->` 比對到整數，同時把它存進 `i`
- `case String s ->` 比對到字串，存進 `s`
- `case String s when s.isEmpty() ->` 還可以加條件守衛，更細緻
- `case null ->` 直接處理 null，再也不怕 NPE（NullPointerException）偷襲

---

## Pattern Matching for switch 範例

來看範例，`describe(Object o)` 這個方法接收任意物件。

傳進來是整數？印「整數：xx」。傳字串？先檢查是不是空字串，是的話印「空字串」；不是就印「字串：xx」。傳 null？印「null 值」。什麼都不是？印「其他型別」。

這個寫法比以前用一堆 `instanceof` + `(Integer) o` 強制轉型，不知道優雅多少倍。

注意：這功能在 Java 17 是**預覽版**，要加 `--enable-preview` 才能用。Java 21 才正式畢業。所以如果你的環境是 JDK 17，記得這個細節。

---

## Sealed Class 搭配 switch（Java 17）

最後介紹一個超強組合技：**Sealed Class + Switch Expression**。

`sealed interface` 限制了這個介面能被哪些類別實作——你宣告了就只有你列的那幾個。

好處是什麼？**編譯器幫你把關**。你在 switch 裡處理 Shape，編譯器知道 Shape 只有 Circle 和 Rectangle 兩種，如果你漏掉其中一個，編譯就直接報錯——不需要 default，因為已經涵蓋全部了。

這對大型系統非常有用。以後系統加了新的 Shape，你的 switch 馬上就編譯失敗、提醒你記得處理新情況——而不是在執行時才爆炸。

這就是靜態型別語言的優勢：**讓錯誤盡早出現**。

## 專題一：BMI 計算（說明 + 程式碼）

好，進入第三部分——動手做！

第一個專題是 BMI 計算。公式很簡單：體重除以身高的平方。

判斷標準：
- 小於 18.5：過輕
- 18.5 到 24：正常
- 24 到 27：過重
- 27 以上：肥胖

這個程式是 `if-else if-else` 鏈的完美練習場。注意條件的順序：從最小的 `< 18.5` 開始，往上走——反過來寫的話邏輯就會出問題。

`printf("BMI = %.2f%n", bmi)` 這行讓你的輸出格式漂亮，保留兩位小數。你要是直接 `println(bmi)`，可能會印出一串有夠長的浮點數，然後你的 BMI 就變成天文數字。

## 專題二：生肖判斷（說明 + 程式碼）

第二個專題：查生肖！

中國十二生肖按年份除以 12 的餘數來判斷。2024 年除以 12 餘 8，餘數 8 對應龍——所以 2024 是龍年！（恭喜各位龍年出生的同學，你們終於可以驕傲一下。）

這個程式非常適合用 **Switch Expression** 來寫——12 個 case，沒有複雜邏輯，箭頭語法超整齊，一目了然。

一個小挑戰：你能不能改成「輸入你的出生年份，輸出你的生肖」？試試看，這就是你的課後作業了。

## 專題三：火箭倒數升空

第三個專題最帥——**火箭倒數升空**！

這個程式結合了 `for` 迴圈（下一章會更深入）和 `if-else if-else` 鏈。

倒數從 10 開始：
- 大於 3：普通倒數，印「10...」「9...」「8...」
- 3 到 1：進入「準備」階段，加上「準備！」
- 0：點火升空！

這個例子想讓你看到：**迴圈和條件判斷是搭配使用的**。`for` 控制「重複幾次」，`if-else` 控制「每次要做什麼」。兩個概念組合起來，能做的事情就多了。

說真的，你跑這段程式的時候，會有一種莫名的成就感——雖然火箭是假的，但感覺是真的。

## 練習一：成績等第轉換（任務說明 + 解題提示）

好，進入練習時間！第一題：**成績等第轉換**。

任務很直覺：輸入一個分數，輸出 A、B、C、D、F 的等第。90 以上 A，80 到 89 B，依此類推，59 以下直接 F。

解題提示：用 `if-else if-else` 鏈，**從最高分往下判斷**。

為什麼要從高往低？因為如果你先判斷 `>= 60`，那 83 分的人就被歸類成「及格」就結束了，永遠到不了 B 的分支。

程式骨架已經給你了，`grade = "B"` 那行的條件自己填進去。這種「填空題」風格是很好的練習方式——你不用從零開始，但你必須真的理解才能填對。

---

## 練習二：星期幾判斷器（任務說明 + 解題提示）

第二題：**星期幾判斷器**，而且這次要用 **Switch Expression** 來寫！

輸入 1 到 7，1 到 5 是工作日，6 到 7 是假日，超出範圍輸出「無效輸入」。

用 Switch Expression 的多值 case：`case 1, 2, 3, 4, 5 -> "工作日";`——一行搞定五天，太爽了。

這題的目的是讓你親自感受 Switch Expression 的好用——以前傳統 switch 要寫五個 case 加五個 break，現在一行。這就是 Java 14 帶來的生活品質提升。

空格那行 `case ______` 讓你填寫週末的判斷條件，試試看！
