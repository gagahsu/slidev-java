# Ch06 迴圈控制 — 演講稿

## 封面：迴圈控制

好，歡迎大家！今天我們要來聊一個讓程式「活起來」的核心技能——**迴圈**。

你有沒有想過，電腦為什麼比人類強？不是因為它比較聰明，是因為它**不怕重複**。你叫它做同一件事一百萬次，它不會嘆氣、不會抱怨、也不會說「我今天狀態不好」。這個神奇的能力，靠的就是迴圈。

說真的，迴圈是什麼？就是「讓程式一直做某件事，直到某個條件達成為止」。就像你每天早上刷牙，刷上刷下左刷右刷，重複動作直到你覺得夠乾淨才停。只不過程式比你精準，它用的不是感覺，是數字。

今天我們會學三種迴圈：`for`、`while`、`do-while`，還有配套的 `break`、`continue`、標籤語法，以及幾個超酷的實際應用。準備好了嗎？我們開始！

## 第一部分：for 迴圈

進入第一部分，主角登場——`for` 迴圈。

這個迴圈是迴圈界的班長，最常用、最整齊，適合「我知道要做幾次」的情況。

---

## 6-1 for 迴圈語法 + 範例

`for` 迴圈的結構長這樣：括號裡有三個東西，用分號隔開。

第一個是**初始化**——你跟程式說「從哪裡開始數」，只跑一次。第二個是**條件**——每次跑迴圈之前都會檢查，條件不成立就停下來。第三個是**更新**——每次跑完一圈之後，變數要怎麼變，通常是 `i++`。

執行順序記起來：初始化 → 條件 → 程式碼 → 更新 → 條件 → 程式碼 → 更新 → ... → 條件為 false，停！

來看範例：`for (int i = 1; i <= 5; i++)`，這段程式會從 1 數到 5，每次印出 i，輸出就是 `1 2 3 4 5`。

步長可以自訂，想每次跳兩格就寫 `i += 2`，想倒著數就寫 `i--`。程式語言就是這麼彈性。

---

## 6-1 Enhanced for-each 迴圈 + 範例

除了傳統 `for`，Java 還有一個**更懶的版本**——for-each，正式名稱叫 enhanced for 迴圈。

它的語法是：`for (型別 變數 : 陣列或集合)`。你不需要管索引，程式自動幫你一個一個取出來。

來看範例：有一個成績陣列 `{85, 92, 78, 95, 88}`，用 for-each 就可以直接把每個分數取出來印。超簡潔！

不過聽好了——for-each 有個限制：**只能讀，不能改**。你沒辦法透過它修改陣列裡的值，也拿不到索引。所以如果你需要「改第三個元素」或「知道現在是第幾個」，還是乖乖用傳統 for 迴圈。

---

## 第二部分：巢狀 for 迴圈

進入第二部分——巢狀迴圈，也就是**迴圈裡面有迴圈**。

聽起來很嚇人？其實就像時鐘。時針走一格，分針跑一圈。外層迴圈是時針，內層迴圈是分針。

---

## 6-2 巢狀 for 迴圈結構 + 九九乘法表

結構很簡單：外層迴圈控制列，內層迴圈控制欄。外層跑一次，內層從頭到尾完整跑完一輪。

所以如果外層跑 n 次、內層跑 m 次，總共就執行 n × m 次。

最經典的例子是**九九乘法表**。外層 i 從 1 到 9，內層 j 從 1 到 9，每次印出 `i*j=結果`。

注意這裡用了 `%-3d` 格式化，意思是「靠左對齊，保留 3 格寬度」，這樣輸出才整齊漂亮，不會歪七扭八。

你說這有什麼用？未來處理二維陣列、矩陣、棋盤這類資料，巢狀迴圈就是你的好朋友。

---

## 第三部分：while 迴圈

第三部分，輪到 `while` 迴圈上場了。

`while` 跟 `for` 的差別在哪？`for` 適合你**知道要跑幾次**的情況，`while` 適合你**不知道要跑幾次，只知道停止條件**的情況。

---

## 6-3 while 迴圈語法 + 範例

語法非常簡單：`while (條件) { ... }`。每次執行前先檢查條件，為 true 就進去跑，為 false 就停下來。如果一開始條件就是 false，那就一次都不執行。

來看範例：`int i = 1; while (i <= 5) { ... i++; }`，效果跟 for 版本一樣，印出 `1 2 3 4 5`。

但這裡有個超常見的坑——**忘記在迴圈裡更新變數**。如果你把 `i++` 這行刪掉，程式就會永遠在那邊跑，俗稱「無限迴圈」，然後你就只能按 Ctrl+C 強制終止。所以記住：while 迴圈一定要確保有辦法讓條件變成 false！

---

## 6-4 巢狀 while 迴圈

`while` 也可以巢狀。結構跟巢狀 for 一樣，外層跑一圈，內層從頭跑完。

這裡要特別注意：內層的計數變數 `j` 必須在**外層每次迭代的時候重新初始化**。如果你把 `int j = 1` 寫在外層之外，第一圈跑完 j 已經等於 4，第二圈就不會再跑了。這個 bug 很隱微，初學者非常容易犯，請務必小心。

---

## 第四部分：do-while 迴圈

第四部分，`do-while` 登場。

這個迴圈有個特別的個性：**它先做，再問你要不要繼續**。不像 `while` 是「先問再做」，`do-while` 是「先做再問」，所以**至少執行一次**，就算條件一開始就是 false。

---

## 6-5 do-while 語法、對比與範例

語法長這樣：`do { ... } while (條件);`。注意結尾有個分號，很多人會忘，compiler 一定幫你記得（用錯誤提醒你）。

三種迴圈比一比：`for` 和 `while` 至少執行 0 次，`do-while` 至少執行 1 次。

來看個誇張的範例：`int i = 10; do { print(i); i++; } while (i <= 5);`。條件 `10 <= 5` 明顯是 false，但程式還是印出了 10。因為它先做了再問，問完發現條件不對，才停下來。

什麼時候用 do-while？最典型的場景是**選單**。你總要先把選單顯示出來，讓使用者看到選項，再根據他的選擇決定要不要繼續。這就是「先做再問」。

---

## 第五部分：無限迴圈與迴圈控制

第五部分，我們來聊**無限迴圈**，以及怎麼用 `break` 和 `continue` 控制迴圈的命運。

---

## 6-6 無限迴圈

無限迴圈，聽名字好像很危險，但其實超常用。

有兩種寫法：`while (true)` 或 `for (;;)`。前者語意清楚，後者省略了 for 的三個部分，效果一樣。

無限迴圈的精髓在於：**自己決定何時離開**。你在裡面用 `break` 設定出口，條件達成就跳出。

實際應用場景：伺服器一直監聽連線、遊戲的主迴圈一直跑、感測器一直讀資料。這些都是「一直等待直到收到停止訊號」的情境，無限迴圈加 break 就是最乾淨的寫法。

---

## 6-7 break 敘述

`break` 的功能：**立刻跳出最近一層的迴圈**，然後繼續執行迴圈後面的程式碼。

就像你在便利商店走道上找東西，`for` 迴圈一格格找，找到了！`break` 一下，直接離開走道，不用再繼續找剩下的格子。

範例：`for (int i = 1; i <= 10; i++) { if (i == 5) break; print(i); }`，輸出是 `1 2 3 4`，碰到 5 就停了，6 到 10 完全沒機會出現。

---

## 6-8 continue 敘述

`continue` 跟 `break` 是兄弟，但個性不同。

`break` 是「我不幹了，掰掰」，直接離開迴圈。`continue` 是「這次我跳過，但下次繼續」，跳過本次迭代剩下的程式碼，直接進入下一圈。

生活比喻：自助餐排隊夾菜，看到苦瓜，`continue`——跳過，繼續往下夾。不是離開餐廳，只是這盤我不要。

範例：`for (int i = 1; i <= 5; i++) { if (i == 3) continue; print(i); }`，輸出是 `1 2 4 5`，3 被跳過了，但 4 和 5 還是有跑到。

---

## 第六部分：迴圈標籤（Label）

第六部分，進階技能——**標籤**。

一般的 `break` 只能跳出最近一層迴圈。但如果你在雙層迴圈裡，想一次跳出兩層怎麼辦？這時候就需要標籤了。

---

## 6-9 迴圈標籤語法、break 與 continue

標籤語法：在迴圈前面加上 `標籤名稱:`，然後 `break 標籤名稱` 或 `continue 標籤名稱`，就可以精準控制要跳到哪一層。

`break outer` 的範例：雙層迴圈，i 從 0 到 2、j 從 0 到 2。當 `j == 1` 時執行 `break outer`，直接跳出外層迴圈。輸出只有 `0,0`，因為 j 一跑到 1 就整個結束了。

`continue outer` 的範例：當 `j == 1` 時執行 `continue outer`，跳過外層迴圈本次剩餘的內容，直接進外層下一圈。輸出是 `0,0  1,0  2,0`，每列只印了 j=0 的那筆，j=1 以後都被跳過。

什麼時候用？搜尋二維陣列時，找到目標就可以直接用 `break outer` 跳出，比用旗標變數再多加判斷優雅多了。

## 第七部分：Scanner 輸入檢查

第七部分，回到現實——**輸入驗證**。

寫程式最怕什麼？使用者輸入奇怪的東西。你跟他說「請輸入年齡」，他輸入「我不告訴你」，然後你的程式就 crash 了。

---

## 6-10 Scanner 輸入驗證語法 + 完整範例

解決方法：用 `while` 搭配 `sc.hasNextInt()` 做驗證。

`sc.hasNextInt()` 會回傳 true 或 false，告訴你下一個輸入是不是整數。如果不是，就呼叫 `sc.next()` 把那個垃圾輸入吃掉丟棄，然後繼續迴圈，再次要求輸入。

完整範例：要使用者輸入正整數年齡。用 `while (age <= 0)` 包起來，裡面先判斷 `sc.hasNextInt()`，是整數才讀取，不是就提示錯誤並丟棄。讀到整數之後還要檢查是不是正數，不是的話繼續要求。這樣雙重把關，使用者想搗亂也很難。

---

## 6-10 while(true) + break 輸入模式

另一個常見模式：`while (true)` 無限讀取，直到使用者輸入特定字詞才 `break` 離開。

範例：持續讀取使用者輸入的每一行，如果輸入 "bye"（不分大小寫）就停止，否則把輸入印回去。

這是互動式程式的標準結構，聊天機器人、指令列工具都長這樣。使用者說「bye」，我們就優雅地說再見，而不是直接當掉。

## 6-11 累加與計數 + 找最大最小值

迴圈最常做的三件事：**加總、計數、找極值**。

累加記得初始值設 0，乘積記得初始值設 1（不能設 0，乘任何東西都是 0）。這是常識，但初學者真的會忘。

範例：1 加到 100 的總和，同時計算偶數有幾個。`sum = 5050`，`count = 50`，一個迴圈搞定兩件事，很 CP 值。

找最大最小值的技巧：把 `max` 和 `min` 初始化為**陣列第一個元素**，不是 0、不是 `Integer.MIN_VALUE`，就是第一個元素。然後用 for-each 逐一比較，遇到更大的就更新 max，遇到更小的就更新 min。邏輯簡單，不容易出錯。

## 6-12 估算圓周率（萊布尼茨公式）

第一個專題：用程式算出 π！

萊布尼茨公式：π/4 = 1 - 1/3 + 1/5 - 1/7 + ...，正負交替的奇數倒數之和。

程式跑一百萬次迭代，用 `i % 2 == 0` 判斷正負號，每次加或減 `1 / (2i+1)`，最後乘以 4 就得到 π 的近似值。

跑完之後，你會得到 `π ≈ 3.141592`，精確到小數點後六位！這就是數學的美麗——簡單的公式，重複夠多次，就能逼近無理數。下次有人問你圓周率，你可以說「我是用程式算的」，聽起來很厲害吧。

---

## 6-12 雞兔同籠

第二個專題：**雞兔同籠**！這是小學數學名題，沒想到用程式三秒解決。

題目：35 個頭、94 條腿，雞跟兔各幾隻？

暴力列舉法：假設雞的數量從 0 到 35，每次算兔子的數量是 35 減雞，然後算總腿數是否等於 94。符合就印出答案，然後 `break` 離開。

答案是雞 23 隻、兔 12 隻。驗算：23×2 + 12×4 = 46 + 48 = 94，正確！

這叫做**窮舉法**，電腦不怕累，一個個試過去，找到就停。你可能覺得這樣很笨，但對很多問題來說，窮舉是最可靠的解法。

---

## 6-12 國王的麥粒

第三個專題：**國王的麥粒**，這個故事要讓你對「指數成長」產生敬畏。

故事是這樣的：棋盤有 64 格，第 1 格放 1 粒、第 2 格放 2 粒、第 3 格放 4 粒……每格都是前一格的兩倍。問：64 格加起來共幾粒？

程式用 `long` 型別，從 1 開始，每圈乘以 2，累加到 total。結果是 18,446,744,073,709,551,615，大約 1.8 乘以 10 的 19 次方。

這個數字有多大？全世界現在的小麥年產量大約是 7 億噸，換算成粒數大概是 10 的 16 次方。所以這個答案大約等於**全球 1000 年的小麥產量**。國王當然付不起！

還有一個重要提醒：**必須用 `long`，不能用 `int`**。`int` 只有 32 位元，最大值約 21 億，早在第 31 格就溢位爆掉了，結果會完全錯誤。這個 bug 不會有 compiler 錯誤，只會給你一個沉默的錯誤答案，最危險的那種。

## 三種迴圈對比

來做個複習總整理。

三種迴圈的選擇原則很簡單：
- **知道要跑幾次**？用 `for`。
- **不知道次數，但有停止條件**？用 `while`。
- **至少要執行一次**（像選單）？用 `do-while`。

記住：`for` 和 `while` 最少跑 0 次，`do-while` 最少跑 1 次。這個差異決定你選哪個。

## 練習一：FizzBuzz（任務說明 + 解題提示）

好，進入實作時間！第一個練習是大名鼎鼎的 **FizzBuzz**——這個題目在面試裡也很常見，現在就來練熟它。

規則：從 1 數到 50，能被 3 整除印 Fizz，能被 5 整除印 Buzz，能被 15 整除印 FizzBuzz，其他就印數字本身。

關鍵提醒：**判斷順序很重要**！一定要先判斷 15，再判斷 3 和 5。因為能被 15 整除的數字也能被 3 和 5 整除，如果先判斷 3 或 5，FizzBuzz 就永遠不會出現了。

解法就是標準的 `if-else if-else` 串聯，每個條件互斥，乾淨俐落。

---

## 練習二：數字金字塔（任務說明 + 解題提示）

第二個練習：**數字金字塔**！

輸出長這樣：第一列只有 1，第二列有 1 2，第三列有 1 2 3，以此類推，一共 n 列。

這就是巢狀迴圈的經典應用。外層 `i` 控制現在是第幾列，內層 `j` 從 1 數到 i，每次印出 j。印完一列記得用 `println()` 換行。

試著先在腦海中模擬執行過程：i=1 時，內層跑 j=1，印 1，換行。i=2 時，內層跑 j=1,2，印 1 2，換行。以此類推。把這個思路理清楚，巢狀迴圈就不難了。
