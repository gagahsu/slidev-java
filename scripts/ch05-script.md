## 第一部分：程式設計的專有名詞（4-1 表格 + 範例）

好，先來搞定術語。你可能覺得這些名詞聽起來很正式，但我保證，一個範例就全部清楚了。

先看四個詞：**運算元（operand）**、**運算子（operator）**、**運算式（expression）**、**敘述（statement）**。

我來用白話說：

「運算元」就是你要算的東西，像是 `a`、`b`、`5`，這些都是。
「運算子」就是動作符號，`+`、`-`、`*`，告訴電腦要做什麼。
這兩個合在一起，就是一個「運算式」，比如 `a + b`，它會產生一個值。
最後，把運算式加上分號，就變成一條完整的「敘述」，像是 `int c = a + b;`

有個口訣幫你記：「運算元是數字，運算子是符號，合在一起是運算式，加上分號變敘述。」

所以你看這段程式：
```
int a = 5;
int b = 3;
int c = a + b;  // a + b 是運算式，這整行是敘述
System.out.println(c); // 輸出 8
```

`a` 是運算元，`+` 是運算子，`a + b` 是運算式，`int c = a + b;` 是敘述。

就這樣，術語解決了！以後教授問你「這是什麼運算式？」你就知道怎麼回答了。

## 第二部分：指定運算子（4-2）

接下來說「指定運算子 `=` 的特殊用法」。

注意，這個 `=` 不是數學的「等號」，是 Java 的「指定」，意思是「把右邊的值塞進左邊的變數」。

那特殊在哪裡呢？它是**由右至左**執行的！

所以你可以寫這種東西叫「鏈式賦值」：

```java
a = b = c = 0;
```

電腦讀這行的順序是：先把 `0` 指定給 `c`，`c` 的值再指定給 `b`，`b` 的值再指定給 `a`。最後三個變數都是 `0`。

這個技巧在初始化一堆變數時很好用。
比如你要把十個計數器全部清零，你不用寫十行，可以連環賦值一口氣搞定。

聽起來很帥對吧？就是這個，鏈式賦值。

## 第三部分：基本數學運算（4-3 表格 + 範例 + Math）

好，進入最親切的部分——加減乘除，Java 都有，對應你國小學過的四則運算。

加 `+`、減 `-`、乘 `*`、除 `/`、取餘數 `%`，就這五個。

不過這裡有個**大地雷**要特別說：**整數除法**。

你看，`10 / 3` 在 Java 裡的結果是 `3`，不是 `3.33`！

為什麼？因為兩個 `int` 相除，Java 會直接截掉小數部分，只保留整數商。
這跟你在計算機上按的結果不一樣！

所以什麼時候你會踩這個雷？比如你在算成績平均、算 BMI，用 `int / int` 就會偷偷把小數丟掉，最後答案差一大截。

解法很簡單：把其中一個改成 `double`，像 `10.0 / 3` 或 `(double) 10 / 3`，結果就會是 `3.333...` 了。

另外，`%` 取餘數也很實用。`10 % 3 = 1`，就是 10 除以 3 商 3、餘 1。這個在判斷偶數、分頁計算都超常用，記起來。

說到數學，Java 還給了我們一個好朋友叫 **Math 類別**，裡面有一堆現成的數學方法：

- `Math.abs(-5)` 取絕對值，得 `5`
- `Math.pow(2, 8)` 算 2 的 8 次方，得 `256.0`
- `Math.sqrt(144)` 開根號，得 `12.0`
- `Math.max(42, 99)` 找最大值，得 `99`
- `Math.round(3.5)` 四捨五入，得 `4`
- `Math.PI` 是圓周率，`3.14159...`

最棒的是，Math 屬於 `java.lang` 套件，完全不需要 `import`，直接用就對了！是不是超方便？

## 第四部分：複合指定運算子（4-4 表格 + 範例）

好，現在來說「複合指定運算子」，也就是 `+=`、`-=`、`*=`、`/=`、`%=` 這些東西。

說穿了，就是懶人版的寫法。

`a += b` 等於 `a = a + b`，意思完全一樣，只是少打幾個字。

比如你有一個 `score` 分數，每次加分、扣分、乘倍數，不用每次都寫 `score = score + 20`，直接 `score += 20` 就好。

看這個範例：
```
score = 100;
score += 20;  // 120
score -= 10;  // 110
score *= 2;   // 220
score /= 4;   // 55
score %= 7;   // 6（55 除以 7 餘 6）
```

就這樣，分數從 100 一路跑到 6，可能是被當了（笑）。

這些運算子在計數器、累加器、遊戲分數管理裡超常見。記起來就行，沒什麼特別難的。

## 第五部分：比較運算子（4-5）

進入第五部分！這裡開始要跟布林值 `true`/`false` 打交道了。

先說「比較運算子」，又叫「關係運算子」。就是拿兩個值來比大小：

- `==` 等於
- `!=` 不等於
- `>`、`<`、`>=`、`<=`

結果只有兩種：`true` 或 `false`。

這裡有個**超級常見的錯誤**，幾乎每個 Java 初學者都會踩：**把 `==` 寫成 `=`**！

`==` 是「比較」，`=` 是「指定」，長得很像但意義完全不同。

如果你在 `if` 裡面寫 `if (a = 5)`，Java 編譯器會給你一個錯誤，因為它說「我要的是布林值，你給我一個指定動作幹嘛？」

所以請記住：**比較用雙等號 `==`，指定用單等號 `=`**。這個分清楚，少掉一半的 bug。

## 第六部分：邏輯運算子與短路求值（4-5 邏輯 + 範例）

再來是**邏輯運算子**：`&&`（AND）、`||`（OR）、`!`（NOT）。

這三個的概念很直觀：

- `&&`：兩個條件都要 true，結果才是 true。就像你進考場，「有准考證」而且「有帶文具」，兩個都要。
- `||`：任一條件 true，就是 true。就像週末出門，「天氣好」或者「朋友約」，有一個就去。
- `!`：反轉，`true` 變 `false`，`false` 變 `true`。

然後這裡有個很帥的進階概念：**短路求值（Short-Circuit Evaluation）**。

什麼意思呢？

用 `&&` 的時候，如果左邊已經是 `false`，Java 直接判定結果為 `false`，右邊**根本不會執行**！

用 `||` 的時候，如果左邊已經是 `true`，右邊也**不會執行**！

這聽起來只是小細節，但其實超重要！看這個例子：

```java
int x = 0;
boolean result = (x != 0) && (100 / x > 1);
```

如果不短路的話，右邊 `100 / x` 就是除以零，程式直接爆炸！
但因為短路求值，左邊 `x != 0` 是 `false`，右邊根本不跑，`result` 直接得到 `false`，程式安全無虞。

這個特性可以幫你防雷。記起來！

## 第七部分：位元運算子（4-6 邏輯 + 移位）

好，進入位元運算！這塊很多人第一次看會覺得「這是什麼鬼」，但聽我說完你會覺得它其實很有邏輯。

我們先從位元邏輯運算子說起：`&`、`|`、`^`、`~`。

這四個跟上面的邏輯運算子長得很像，但**作用對象不同**。邏輯運算子是針對整個布林值，位元運算子是針對數字的**每一個 bit** 去做操作。

舉個例子：
- `5` 的二進位是 `0101`
- `7` 的二進位是 `0111`

`5 & 7`，每個 bit 逐一做 AND：
```
0101
0111
----
0101  → 5
```

`5 | 7`，每個 bit 逐一做 OR：
```
0101
0111
----
0111  → 7
```

`5 ^ 7`，相同得 0，不同得 1（XOR）：
```
0101
0111
----
0010  → 2
```

`~5` 就是把所有 bit 反轉，結果是 `-6`。這個跟補數有關，可以記一個規律：`~N = -(N+1)`。

---

然後是**位移運算子**：`<<`、`>>`、`>>>`。

左移 `<<`：把所有 bit 向左移，右邊補 0。`4 << 2` 就是 `4 * 4 = 16`。
右移 `>>`：把所有 bit 向右移，左邊補符號位。`4 >> 1` 就是 `4 / 2 = 2`。
無符號右移 `>>>`：不管正負，左邊一律補 0。

這些在底層效能優化很常用，因為位移運算比乘除法更快，CPU 直接對 bit 操作，一個時脈就搞定。

一般應用層的程式不一定常用到，但面試很愛考，所以還是要認識一下！

---

## 第八部分：運算子優先順序（4-7 兩張表格 + 範例）

好，來看運算子優先順序表。

你一定記得小學老師說：「先乘除後加減」。Java 也有一模一樣的概念，只是表格比較長，因為運算子更多。

我幫你抓重點，從高到低：

1. **括號、陣列索引、點（.）成員存取** — 最高優先
2. **後置 `++` `--`、一元運算、`~` `!`**
3. **`*` `/` `%`**
4. **`+` `-`**
5. **位移 `<<` `>>` `>>>`**
6. **比較 `<` `>` `<=` `>=` `instanceof`**
7. **`==` `!=`**
8. **位元 `&` `^` `|`**（三個各一層）
9. **邏輯 `&&` `||`**
10. **三元 `?:`**
11. **指定類 `=` `+=` `-=` ...** — 最低優先

看這個例子：

```java
int result = 100 + 200 / 10 - 3 * 10;
```

電腦怎麼算？先算 `200/10 = 20`，再算 `3*10 = 30`，然後 `100 + 20 - 30 = 90`。

這就是優先順序在發揮作用。

不過，說真的，你不需要把這整張表背下來。有個更簡單的策略：**遇到不確定的地方就加括號！**

`(100 + 200) / (10 - 3) * 10` 這樣寫，一眼就看清楚計算順序，還不容易出錯。括號是你的好朋友。

## 第九部分：資料型態轉換（4-8 自動提升 + 強制轉型）

好，來到型態轉換這個環節，這裡有兩個方向：**自動提升**和**強制轉型**。

先說**自動型態提升**。

當兩個不同型態的數值一起做運算，Java 會自動把「小的型態」提升成「大的型態」，避免資料損失。
規則是：有 `double` 就提升到 `double`；有 `float` 就提升到 `float`；有 `long` 就提升到 `long`；否則至少提升到 `int`。

注意最後那條：`byte + byte` 的結果不是 `byte`，而是 `int`！
所以你寫：
```java
byte op1 = 4;
byte op2 = 5;
byte result = op1 + op2;  // 編譯錯誤！
```
Java 會告訴你：「我算出來的是 int，你不能直接放進 byte 裡。」
要修正，需要加強制轉型：`byte result = (byte)(op1 + op2);`

---

再說**強制型態轉換（Casting）**。

這是你主動告訴 Java：「我知道可能會有損失，但就是要轉！」

語法是在值前面加上 `(目標型態)`：

```java
double pi = 3.14159;
int n = (int) pi;    // 小數直接截掉，n = 3
```

注意是**截掉**，不是四捨五入！`3.99` 強制轉成 `int` 是 `3`，不是 `4`！

還有一個有趣的例子：

```java
int x = 65;
char ch = (char) x;   // ch = 'A'
```

65 是 ASCII 碼的 'A'，所以整數可以轉成字元。這個在字元處理或加密算法裡有時候會用到。

型態提升方向記一下：`byte → short → int → long → float → double`
從窄到寬是自動，從寬到窄需強制。就像把水倒進大桶子可以自動溢，但要從大桶子倒回小杯子，你得自己拿杓子舀——而且可能會灑出去！

## 第十部分：Scanner 輸入與字串轉數值（4-9 三張合一）

好，來說輸入！目前我們的程式都是自己設定數字，但真實世界的程式要能讓使用者輸入資料。Java 用 **Scanner** 來做這件事。

`Scanner` 在 `java.util` 套件裡，所以要先 `import java.util.Scanner;`

然後建立一個 Scanner 物件：
```java
Scanner scanner = new Scanner(System.in);
```
這就像是把一個「耳朵」插進標準輸入，準備聽使用者說話。

常用方法：
- `nextInt()` — 讀整數
- `nextDouble()` — 讀浮點數
- `nextLine()` — 讀整行（含空格）
- `next()` — 讀一個詞（遇空白停）

這裡有個**超級常見的陷阱**要特別說：

`nextInt()` 讀完數字之後，它不會消耗那個換行符號。
所以如果你接著呼叫 `nextLine()`，它會讀到一個空字串，什麼都沒有。

解法：在 `nextInt()` 和 `nextLine()` 中間，多插一行 `scanner.nextLine()` 把換行吃掉。

這個 bug 我看過無數人踩，而且踩了以後非常難 debug，因為程式跑起來看起來像跳過輸入。記起來，以後救你大忙。

---

另外，字串轉數值也很常用：

- `Integer.parseInt("42")` — 字串轉 int
- `Double.parseDouble("3.14")` — 字串轉 double
- `String.valueOf(99)` — 數值轉字串

這在網路傳資料、讀檔案的時候特別常見，因為很多輸入都是字串格式，要自己轉成數字才能計算。

```java
String numStr = "100";
int n = Integer.parseInt(numStr);   // 100
System.out.println(n + 1);          // 101
```

看，字串 "100" 轉成 int，就能加減了。如果不轉，`"100" + 1` 會變成字串 `"1001"`，這是字串串接，不是數字相加！

## 第十一部分：import 與 java.lang 套件（4-10）

好，說到 `import`，我們來快速搞清楚這件事。

Java 的類別都放在「套件（package）」裡。你要用哪個套件的類別，就要先 `import`。

但有一個例外：**`java.lang` 套件不需要 import！**

為什麼？因為它實在太基礎、太重要了，Java 編譯器直接幫你自動匯入。

`System`、`String`、`Math`、`Integer`，這些你每天用的東西，都在 `java.lang` 裡，通通不用 import。

反過來，`Scanner` 在 `java.util` 裡，就要自己寫 `import java.util.Scanner;`，或者懶人版 `import java.util.*;`（星號代表整個套件）。

這張表記一下：
- `java.lang` — 自動匯入，不需要手動寫
- `java.util` — 需要 import（Scanner、ArrayList 等）
- `java.io` — 需要 import（檔案操作）

之後學更多類別，你就會知道它們分別住在哪個套件裡，需不需要 import。

## 第十二部分：程式敘述的結合與分行（4-11）

這個部分很快，但值得說一下。

Java 的敘述是靠**分號 `;`** 結尾，不靠換行。所以換行對 Java 來說，只是給人看的格式，電腦根本不在意。

這表示你可以：

一行寫多個敘述（合法但難讀）：
```java
int a = 1; int b = 2; int c = 3;
```

或者一個敘述分很多行（推薦，當運算式很長的時候）：
```java
double result = 100.0
              + 200.0
              - 50.0;
```

後者讀起來很清楚，每行做什麼一目了然。

原則就一個：**程式碼是給人讀的，其次才是給電腦跑的**。
所以排版、換行，都是為了讓你和你的隊友能更快看懂程式在做什麼。

## 第十三部分：專題一 — 溫度轉換（4-12）

好，進入壓軸的專題！

第一個：**溫度轉換**，攝氏換華氏。

這個有公式：`°F = °C × 9 / 5 + 32`

對，你沒看錯，就是這個你高中物理學過的東西。現在我們用程式來算。

有個要注意的地方：這裡要寫 `9.0 / 5.0`，不能寫 `9 / 5`！
因為 `9 / 5` 兩個都是整數，Java 整數除法會直接給你 `1`，然後 `1 + 32 = 33`，不管你輸入幾度都是 33 華氏度……這結果毫無意義。

用 `9.0 / 5.0`，結果才是正確的 `1.8`。

所以這個溫度轉換，除了考你公式，也在考你**有沒有注意整數除法的坑**。現在你知道了，以後遇到就不會踩！

## 第十四部分：專題二 — 高斯數學（4-12）

第二個專題：**高斯數學**，計算 1 + 2 + 3 + ... + n 的總和。

這個有個超帥的故事：傳說高斯小時候，老師出這道題想讓學生算很久，結果高斯幾秒內就算出來了。怎麼算的？

他發現 `1 + 100 = 101`，`2 + 99 = 101`，...，共 50 對，所以總和是 `50 × 101 = 5050`。

這就推出了公式：`sum = n × (n + 1) / 2`

這章我們提供兩種解法對比：

一種是**迴圈累加**，從 1 跑到 n 一個一個加起來；
另一種是**高斯公式**，一行搞定。

迴圈結果和公式結果應該完全一樣。如果不一樣，代表有 bug！

這個專題的意義是：同一個問題，有笨方法也有聰明方法。程式設計不只是讓程式跑起來，更是找到更好的解法。高斯小時候就懂了，我們現在學起來。

## 第十五部分：練習一 — BMI 計算機

好，來到練習環節！

第一個練習：**BMI 計算機**。

公式是：`BMI = 體重(kg) / (身高(m))²`

注意，身高要從公分轉換成公尺：`heightM = height / 100.0`。注意是 `100.0` 不是 `100`，又是整數除法的問題！

然後計算 BMI：
```java
double bmi = weight / (heightM * heightM);
```

或者用 `Math.pow`：
```java
double bmi = weight / Math.pow(heightM, 2);
```

輸出用 `printf` 格式化到小數點後兩位：
```java
System.out.printf("BMI = %.2f%n", bmi);
```

進階一點，可以加 `if-else` 判斷是過輕、正常還是過重，這個我們下一章就會學到。

這個練習把本章的幾個重點全都串起來了：Scanner 輸入、浮點數除法、Math 方法、格式化輸出。做完這個，代表你這章學扎實了！

## 第十六部分：練習二 — 進階位元操作

第二個練習：**位元操作**。

三個小任務：

**一、判斷奇偶**：用 `&` 運算子。
`(n & 1) == 0` 是偶數，`(n & 1) == 1` 是奇數。
原理：最低位元是 0 就是偶數，是 1 就是奇數。

**二、乘以 4**：用左移運算子。
`n << 2` 等於 `n * 4`，左移幾位就乘以 2 的幾次方。

**三、除以 2**：用右移運算子。
`n >> 1` 等於 `n / 2`，向下取整。

這三個操作比算術運算快，因為 CPU 直接操作 bit，不用做完整的乘除法電路。

在一般 CRUD 應用程式裡，你可能不需要這樣優化。但如果你以後做遊戲引擎、嵌入式系統、高效能計算，這些就是基本工具了。

而且，這種題目在技術面試裡超級常見！考官就愛問：「你能不用乘法算出 n * 4 嗎？」現在你知道答案了。
