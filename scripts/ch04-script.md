## 3-1 認識變數

寫程式，本質上就是在「處理資料」。

資料要放在哪裡？放在記憶體裡。那你要怎麼找到它？你要給它一個名字。

這個「在記憶體裡佔一塊空間，然後給它取名字」的東西，就叫做「變數」（Variable）。

想像一下你家廚房的抽屜。每個抽屜你都貼了標籤——「刀叉」、「湯匙」、「備用電池（老是放錯地方的那種）」。變數就是這些貼了標籤的抽屜，你隨時可以根據標籤名字找到你要的東西。

---

## 什麼是變數？

來看這行程式碼：

```java
int age = 25;
```

拆解一下，這行有四個部分。

`int`——這是「資料型態」，告訴 Java 這個盒子只能裝整數，不能裝別的。就像你的刀叉抽屜不能拿來放備用電池。

`age`——這是「變數名稱」，你替這塊記憶體空間取的名字，你之後就用這個名字找到它。

`= 25`——這是「初始值」，就是你第一次放進盒子裡的東西。

最後那個「`;`」——分號。每一行 Java 敘述都要用分號結尾，忘記加的話，編譯器會跳出來跟你說「朋友，你忘了什麼」。

Java 是靜態型別語言，意思是你宣告變數的時候就要決定型態，之後不能再改。不像某些語言，你可以今天放整數、明天放字串——Java 不給你這個自由。

---

## 變數命名規則

好，你可以把變數叫什麼名字？有規則。

規則分兩種：「語法規定」和「命名慣例」。語法規定你不遵守，程式跑不起來；命名慣例你不遵守，程式能跑，但你的同事會想打你。

語法規定就幾條：不能用數字開頭、不能用 Java 的保留字（像 `int`、`class`、`for`，這些已經被 Java 佔用了）、可以用字母、數字、`$`、底線。

命名慣例，最重要的是 camelCase：第一個單字全小寫，後面每個單字的第一個字母大寫。所以「使用者名稱」就是 `userName`，「總分」就是 `totalScore`。

說真的，`userName` 和 `un` 都合法，但哪個比較好讀？一眼就看出來了吧。

記住：名字要有意義，用完整單字，不要用縮寫。三個月後你看到自己取的名字 `un`，你會不知道那是什麼。

---

## 變數的三種分類

Java 的變數依照放在哪裡，分成三種。

第一種，「區域變數」——放在方法裡面，只在那個方法裡有效，像是借來的東西，出了這個方法就消失了。最重要的是：Java **不會**幫它設預設值，你宣告了沒初始化就拿去用，編譯器直接報錯，非常硬派。

第二種，「實例變數」——放在類別裡面，每個物件各自擁有一份。Java 會自動給預設值，`int` 給 `0`，`boolean` 給 `false`，物件給 `null`。

第三種，「類別變數」——加了 `static` 關鍵字，所有物件共用同一份，改了就全部都改。

最容易踩坑的是區域變數那個「沒有預設值」的規定。新手常犯的錯是宣告了一個 `int local;` 然後直接拿去算數，然後就爆了。

記住：區域變數，宣告完一定要馬上給值。

---

## var 型態推斷（Java 10+）

Java 10 之後，給了你一個偷懶的工具，叫做 `var`。

傳統寫法你要打 `String name = "炭治郎";`。用 `var` 的話，你就寫 `var name = "炭治郎";`，讓編譯器自己猜你要什麼型態。

聽起來很像動態語言的感覺？但要澄清一件事：`var` 不是動態型別。編譯完之後，型態就固定了，`var name` 編譯後就是 `String name`，一模一樣，只是你少打了幾個字。

那什麼時候適合用？當型態名稱超級長的時候。比如說 `new ArrayList<HashMap<String, Integer>>()`，你每次都要打這一長串，但用 `var` 就直接跳過去，乾淨很多。

限制是：`var` 只能用在區域變數，而且宣告的時候要同時賦值，不然編譯器不知道你要什麼型態。

## 3-2 基本資料型態

好，進到第二節。

Java 有 8 種「基本資料型態」，英文叫 Primitive Types。

為什麼說「基本」？因為它們是語言裡最底層的東西，不是物件，直接住在記憶體的 Stack 上，存取速度快。可以把它們想成 Java 這棟大廈的鋼筋——其他所有東西都建在它們上面。

這 8 種型態你總有一天要全部認識，不過今天我們先瀏覽一遍，有個印象。

---

## 8 種基本資料型態

讓我們看一下這張大表。

整數家族有四個：`byte`（8 位元）、`short`（16 位元）、`int`（32 位元）、`long`（64 位元）。每個是前一個的兩倍大。

小數家族有兩個：`float`（32 位元）、`double`（64 位元）。

然後還有 `boolean`——只有 `true` 和 `false` 兩種值。

最後是 `char`——存單一字元，16 位元，可以表示 65536 個不同的字元。

你需要記住的優先順序是：**整數預設用 `int`，小數預設用 `double`**。其他的有需要再查，不用硬背。

大小記憶法：byte → short → int → long，每次乘以 2，從 8 位一路翻到 64 位。

---

## 整數型態 — 範例

來看整數的實際用法。

`byte b = 127;`——byte 最大就 127，你塞 128 進去，編譯器就跟你說「你多了一個，放不下」。

`short s = 32_000;`——你有沒有注意到這個底線？這是 Java 7 以後支援的數字分隔符。`32_000` 和 `32000` 完全一樣，只是多了底線之後，人眼比較容易讀。就像你在寫金額的時候會用逗號隔開千位。

`long bigNum = 9_876_543_210L;`——注意最後那個 `L`！如果你的數字超過 int 的範圍（大約 21 億），你必須加 `L` 後綴告訴 Java 這是 `long`，不然它會以為你在給一個 `int`，然後報錯。

日常開發幾乎都是用 `int`。只有在存時間戳記或是超級大的數字的時候，才需要換 `long`。

---

## 浮點數型態 — 範例

浮點數兩兄弟：`float` 和 `double`。

`float f = 3.14f;`——注意後面那個 `f` 不能省略，不然 Java 會以為你在給 `double`，然後賦值給 `float` 就出精度錯誤了。

`double d = 3.14159265;`——`double` 不需要後綴，Java 預設小數字面值就是 `double`。

現在我要說一件讓你崩潰的事：浮點數無法精確表示所有小數。`0.1 + 0.2` 在 Java 裡面不等於 `0.3`，會是一個像 `0.30000000000000004` 這樣的奇怪數字。

為什麼？因為電腦是用二進位存小數，有些十進位的小數在二進位裡是無限循環，存不完整。

所以，如果你要做金融計算，絕對、絕對不能用 `float` 或 `double`，請用 `BigDecimal`。否則你會算出 100.00 塊但銀行說你只有 99.99999 塊。

---

## boolean 與 char — 範例

`boolean` 很簡單：只有 `true` 和 `false`。它是所有條件判斷的核心，`if`、`while`，全部都吃 `boolean`。

`char` 用單引號包住一個字元。注意是**單引號**，不是雙引號，雙引號是字串 `String` 用的。

有一個有趣的事：`char` 本質上是一個 16 位的無號整數，所以可以做算術。`'A' + 1` 的結果是 `'B'`，因為 A 和 B 在字元編碼表上是相鄰的。這個特性在操作 ASCII 字元的時候很好用。

不過你現在記住：`char` 放字元、`String` 放字串，單引號 vs 雙引號，這個不要搞混。

---

## 型態轉換 — 擴大轉換（Widening）

資料型態之間可以互相轉換，分兩種：擴大和縮小。

擴大轉換，就是從小型態轉大型態，Java 自動幫你做，你不用寫任何額外的東西。

就像把水從小杯倒進大杯，不會溢出，Java 幫你自動做，你不用操心。

記住那個圖的箭頭方向：byte → short → int → long → float → double。往右走是自動的，Java 幫你。往左走就要你自己動手了。

`char` 也可以自動轉到 `int`，因為 char 本質就是個整數，只是加了字元的面具而已。

---

## 型態轉換 — 縮小轉換（Narrowing）

縮小轉換，從大型態轉小型態，這時候 Java 不幫你做，你要自己加上 `(目標型態)` 的語法，叫做「強制轉型」。

為什麼？因為大杯的水倒進小杯，一定會溢出。Java 不想在你不知情的情況下幫你丟資料，所以要你明確說：「我知道可能會損失資料，我願意承擔後果。」

`double d = 100.99; int i = (int) d;`——結果是 `100`，不是 `101`！不是四捨五入，是直接砍掉小數點後面所有的東西。

更刺激的是 `byte b = (byte) 257;`，結果是 `1`。為什麼？因為 byte 只能裝 -128 到 127，257 超出去了，就從頭循環，截斷後剩 1。

這種溢位的 bug 在初學者的程式裡很常見，記住了。

---

## Autoboxing — 自動裝箱

你剛才學到 `int`、`double` 這些是 primitive。但 Java 的集合類別（`ArrayList`、`HashMap` 等等）只能存「物件」，不能存 primitive。

這就尷尬了，怎麼辦？

Java 為每個 primitive 都準備了一個對應的「包裝類別」——`int` 對應 `Integer`，`double` 對應 `Double`，以此類推。

然後 Java 還提供了「Autoboxing」自動裝箱：當你需要物件的地方用了 primitive，Java 自動幫你包裝起來；反過來用了，Java 自動幫你拆開。

就像你帶便當去公司，你的便當盒（包裝類別）讓便當（primitive 資料）可以被放進公司的冰箱（集合）裡。吃的時候再把便當從盒子裡拿出來。

要注意的是，自動裝箱在效能敏感的迴圈裡會有一點成本，因為每次裝箱都要建立物件。不過一般情況下不用太擔心。

---

## 3-3 字串（String）資料型態

好，進到 3-3，講 String。

你寫程式，每天都在跟文字打交道：姓名、地址、訊息。這些全部都靠 `String`。

String 是你學 Java 會遇到的最重要的東西之一，但它跟剛才說的 primitive 不一樣——它是一個「類別」，是物件。

---

## String 的宣告與特性

宣告 String 很簡單：`String name = "炭治郎";`。雙引號括住你的文字。

但有幾個特性你要記住。

第一，String 是**不可變的**（Immutable）。字串一旦建立，你沒辦法修改它。當你寫 `str = str + "!"`，你不是在修改原本的字串，你是在建立一個全新的字串，然後把變數指向它。

就像你把一張白紙上的字改掉，其實你是揉掉那張紙、拿一張新紙重新寫。原本那張紙還在某個地方飄著，等垃圾回收。

第二，**字串池**（String Pool）。相同內容的字串字面值，Java 會讓它們指向記憶體裡同一個物件，節省空間。

這個 Immutable 特性對效能有影響——如果你在迴圈裡一直串接字串，每次都在製造新物件，那效能就會很慘。這種情況請用 `StringBuilder`，我們在 Ch 13 會詳細介紹。

---

## String 常用操作（基本篇）

String 是物件，所以它有方法可以呼叫。

`length()` 告訴你字串有幾個字元。

`charAt(i)` 給你索引 i 的字元，索引從 0 開始。所以 `"Hello".charAt(0)` 是 `'H'`。

`substring(begin, end)` 擷取子字串，注意是 begin 到 end-1，end 本身不包含。`"Hello".substring(1, 4)` 是 `"ell"`，包含索引 1、2、3，不包含 4。

`toUpperCase()`、`toLowerCase()`，轉大小寫，返回新字串（因為 String 是 immutable，所以原字串沒有被改動）。

這裡只是讓你知道 String 可以呼叫方法，完整的方法庫我們在 Ch 13 會仔仔細細地介紹。

---

## String 的串接與比較

串接字串很簡單，直接用 `+` 號，或者呼叫 `concat()` 方法，效果一樣。

但比較字串這裡有一個大坑，是 Java 面試最常考的問題之一，聽好了。

`==` 在 Java 裡比的是「記憶體位址」，不是「內容」。

如果你用字面值宣告兩個內容相同的字串，它們會因為字串池指向同一個物件，所以 `==` 是 `true`。

但如果你用 `new String("Java")` 建立的字串，它在 Heap 裡是獨立的新物件，跟字面值宣告的 `"Java"` 位址不一樣，所以 `==` 是 `false`。

然後你就會很困惑：「明明內容一樣，為什麼不相等？！」

結論：**比較字串內容，永遠用 `equals()`，不要用 `==`。** 把這句話刻在腦子裡。

## 3-4 常數（Constant）的觀念

第四節，常數。

有些值在程式執行過程中不應該被改變。圓周率是 3.14159...，你不應該在程式某個地方把它改掉。稅率是 5%，你不應該讓某個邏輯意外把它改成 50%。

Java 用 `final` 關鍵字來保護這些值。

---

## final 關鍵字

用法很簡單：宣告的時候加上 `final`。

```java
final int MAX_SCORE = 100;
```

加了 `final` 之後，這個變數就被鎖住了。你如果在後面試圖重新賦值，比如 `MAX_SCORE = 200;`，編譯器在你按「Run」之前就會攔住你，直接報錯。

這不是等到程式跑起來才爆，而是在編譯的時候就抓到，非常安全。

命名慣例：常數用全大寫，多個單字用底線分隔。`MAX_SCORE`、`PI`、`EARTH_RADIUS_KM`。這樣任何人看到全大寫的名字，立刻知道這是一個不可變的常數，不要亂動。

---

## static final — 類別層級的常數

`static final` 組合，是定義「類別常數」的標準寫法。

`static` 的意思是：這個東西屬於類別本身，不屬於任何一個物件。所有物件共用同一份。

`final` 的意思是：這個值不能被修改。

兩個合在一起：全域共用、不可修改。這就是常數最完美的形式。

JDK 裡的 `Math.PI` 就是這樣定義的：`public static final double PI = 3.14159265358979;`。你不需要建立 `Math` 物件，直接 `Math.PI` 就可以用。

在實際開發中，常數通常會集中定義在一個專門的常數類別裡，比如 `Constants.java` 或 `AppConfig.java`，方便統一管理。要改的時候，只要去那一個地方改就好了。

---

## 常數的好處

來看兩段程式碼。

第一段，有個條件 `if (score >= 60)`，還有一個面積計算 `3.14159 * r * r`。

你看到 60，你知道那是什麼意思嗎？如果你三個月後回來看這段程式，你可能會想：這個 60 是什麼？是通關分數？是年齡門檻？是啥？

這種直接寫在程式碼裡的數字，業界有個名字叫「Magic Number（神秘數字）」，是程式碼壞味道的第一名。

第二段，用常數重寫：`final int PASS_SCORE = 60;`，然後條件寫 `if (score >= PASS_SCORE)`。現在意圖非常清晰——哦，這是及格分數。

而且，如果明天規定改了，及格分數要從 60 變成 70，你只需要改一個地方。不然你要在整份程式碼裡搜尋 60，然後一個一個確認哪個是及格分數、哪個又剛好是別的數字。

說真的，不要寫 Magic Number。你的同事和未來的你都會謝謝你。

---

## 3-5 精準控制格式化的輸出

最後一節，格式化輸出。

你之前用 `System.out.println` 印東西，夠用但不夠帥。如果你想讓數字只顯示兩位小數、讓欄位整齊對齊、讓金額有千位逗號，`println` 就做不到了。

這時候你需要 `printf`。

---

## printf 格式語法

`System.out.printf` 的用法：第一個參數是格式字串，後面依序放你要印的資料。

格式字串裡用 `%` 開頭的佔位符來代表資料的位置和格式。

最常用的幾個：

`%d`——整數。`%f`——浮點數，預設印 6 位小數。`%s`——字串。`%c`——單一字元。`%b`——布林值。`%n`——換行。

`%n` 這個要特別說一下，它是跨平台的換行符號。Windows 的換行和 Linux 的換行不一樣，但用 `%n` 就不用擔心這個問題。

把格式字串想像成一個模板，`%d`、`%s` 這些是插槽，後面的引數依序填進去。

---

## 寬度與精確度控制

格式符號可以加上寬度和精確度來控制對齊。

`%10d`——整數至少佔 10 個字元寬，預設右對齊，不夠的地方補空格。數字對齊非常適合這個。

`%-10d`——加上 `-` 旗標就變成左對齊，適合文字欄位。

`%.2f`——小數點後只印 2 位，Java 會自動四捨五入。

`%8.2f`——寬度 8，同時 2 位小數，兩個設定可以組合。

`%05d`——補零旗標，讓 42 顯示成 `00042`。報表序號最常用這個。

這些設定組合起來非常靈活，你可以做出非常漂亮的文字對齊報表。

---

## 格式化旗標速查

讓我們快速看一下常用的旗標。

`-`——左對齊。`0`——補零。`+`——強制顯示正負號。`,`——千位分隔符。`(`——負數用括號表示（財務報表常見）。

其中千位分隔符 `%,d` 超級好用！你直接寫 `printf("%,d", 1000000)` 就輸出 `1,000,000`，不需要自己寫任何格式化邏輯。

`%+.1f` 就輸出帶正負號的一位小數，比如 `+3.1`。財務報表顯示盈虧的時候很方便。

---

## String.format( ) — 格式化成字串

`printf` 是直接印出來。但有時候你想先把格式化的結果存起來，之後再用，或者傳給某個方法——這時候用 `String.format()`。

格式規則完全一樣，只是它不印，而是把格式化好的字串回傳給你，讓你存進變數。

特別注意 `%%`——兩個百分號，輸出一個真正的 `%` 字元。單個 `%` 會被 Java 當成格式符號的開頭，要輸出真正的百分比符號就要打兩個。

`String.format` 非常適合產生報告、log 訊息，因為你可以把結果存起來，之後再決定要印還是要傳給 logger。

## 練習一：個人資料卡

好，到了動手的時間！

這個練習要你宣告四種不同型態的變數——`String`、`int`、`double`、`boolean`——然後用 `printf` 把它們整齊排版輸出。

預期格式你看到了，年齡要右對齊，身高要有一位小數，在學狀態印布林值。

這個練習同時考你兩件事：型態宣告有沒有搞清楚，還有 `printf` 的格式符號用對了沒。

動手試試看，我們等一下對答案。

解題關鍵：`%3d` 讓年齡右對齊至少 3 格，`%.1f` 讓身高只顯示 1 位小數，`%b` 直接印 `true` 或 `false`。每行結尾的 `%n` 負責換行。

## 練習二：成績單格式化

第二個練習，難度稍微升一點。

你要定義三位學生的姓名和分數，用 `static final` 定義及格線 60，然後格式化輸出成一份對齊的成績單。

這個練習把本章所有觀念都用上了：`String` 對齊、`int` 格式化、布林判斷及格與否、還有常數的使用。

解題關鍵：`%-6s` 讓姓名左對齊，`%3d` 讓分數右對齊。

然後三元運算子 `pass1 ? "✓" : "✗"` 是「如果 pass1 是 true，就輸出 ✓，否則輸出 ✗」的精簡寫法。

學完這個練習，你已經能用 Java 寫出像樣的文字報表了。是不是有點成就感？
