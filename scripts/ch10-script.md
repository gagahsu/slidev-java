## 10-1 數學常數（Math.PI、Math.E）

第一個登場的是 `java.lang.Math`。注意，`java.lang` 這個包不需要 import，Java 一開機就幫你載好了，`Math` 類別直接用。

它有兩個內建常數，你一定認識第一個：`Math.PI`，也就是圓周率 π，精確到 15 位小數，`3.141592653589793`。

第二個是 `Math.E`，歐拉數，`2.718281828459045`，自然對數的底數。高中有沒有學過？沒關係，記不住也沒關係，反正 Java 幫你記住了。

所有 Math 的方法都是 `static` 靜態方法，所以不用 `new Math()`，直接 `Math.方法名()` 就好。這設計非常合理——你不會想要 `new` 一個「圓周率物件」出來吧？

算圓面積的範例很直觀：`Math.PI * r * r`，半徑 5 公分的圓，面積大約 78.5 平方公分。這行程式碼，比你用計算機按還快。

## 10-2 Math.random()

好，重頭戲來了——亂數！

`Math.random()` 每次呼叫會吐給你一個 `double`，範圍是 **0.0（含）到 1.0（不含）**。就像轉幸運輪盤，每次停的位置都不一樣，但永遠不會超出邊界。

問題來了：你要的是骰子點數 1 到 6，不是 0.3847 這種奇怪的浮點數，怎麼辦？

記住這個萬用公式：

```
(int)(Math.random() * 範圍大小) + 最小值
```

骰子：範圍大小 6，最小值 1，所以是 `(int)(Math.random() * 6) + 1`。

想要 0 到 9 的整數？`(int)(Math.random() * 10)`，簡單搞定。

這個公式就像抽籤筒，你告訴它「我有幾支籤」、「籤號從幾開始」，它就幫你抽。

## 第二部分：比較與絕對值（10-3 max / min、10-4 abs）

### 10-3 max() / min()：比較兩數大小

`Math.max()` 和 `Math.min()` 是最親民的兩個方法，就是字面上的意思——回傳大的、回傳小的。

但有個隱藏用法值得一提：把兩個方法**巢狀組合**可以做「限制範圍」。

比如說，你的程式有個分數輸入，使用者偷偷輸入了 105 分，你要把它夾在 0 到 100 之間：

```java
int clamped = Math.min(Math.max(score, 0), 100);
```

先用 `max(score, 0)` 確保不低於 0，再用 `min(..., 100)` 確保不超過 100。

這個技巧在遊戲開發、UI 互動裡超常見，記起來。

### 10-4 abs()：求絕對值

`Math.abs()` 就是去掉負號，讓負數變正數，正數不變。

最常用的場景是算「差距」：兩人成績差多少、兩個時間點相差多遠，不管誰大誰小，`Math.abs(a - b)` 直接給你正整數。

有個小陷阱要講：`Math.abs(Integer.MIN_VALUE)` 的結果是負數，因為整數溢位。這個邊界案例面試有時候會考，知道就好，平常不太會踩到。

## 第三部分：捨入方法詳解

### 捨入方法總覽 + 對比範例

接下來是本章最容易搞混的部分——四個捨入方法大亂鬥：`round`、`rint`、`ceil`、`floor`。

先給你一張心智地圖：

- `ceil` 是天花板，往上取，永遠取比你大的整數
- `floor` 是地板，往下取，永遠取比你小的整數
- `round` 是傳統四捨五入
- `rint` 是銀行家用的四捨五入，跟你想的不太一樣

你看那張對比表，`2.5` 這個值最有趣：
- `round(2.5)` → 3（傳統四捨五入，往上）
- `rint(2.5)` → 2.0（取偶數！）
- `ceil(2.5)` → 3.0（天花板）
- `floor(2.5)` → 2.0（地板）

如果只是一般的四捨五入，用 `round` 就好。需要回傳 `double` 的話，用 `rint`。

---

### 10-5 round()：四捨五入

`Math.round()` 的特點是：0.5 一律往**正無限大**取整。

這句話在正數時很自然——1.5 變 2、2.5 變 3。

但在**負數**時要注意：`-1.5` 會變 `-1`，`-2.5` 會變 `-2`。因為往正無限大的方向，負數是往「數線的右邊」走，也就是往 0 靠近。

另外回傳型別有個小細節：傳入 `float` 回傳 `int`，傳入 `double` 回傳 `long`。如果你在做精確的整數運算，記得注意這個。

---

### 10-6 rint()：Banker's Rounding

`Math.rint()` 是所謂的「銀行家捨入法」，也叫做 **Banker's Rounding**。

規則是：0.5 的情況，取**最近的偶數**。

- `rint(1.5)` → 2.0（2 是偶數）
- `rint(2.5)` → 2.0（2 是偶數）
- `rint(3.5)` → 4.0（4 是偶數）
- `rint(4.5)` → 4.0（4 是偶數）

為什麼要這樣？因為傳統四捨五入，遇到 0.5 永遠往上，大量計算後會**系統性偏高**。銀行結算、科學計算不能接受這種偏差。

可以想像：如果你的薪水每個月都被「誤差往上進位」，公司會虧死；但如果「每次恰好偏高一點」，累積起來就是真正的損失。Banker's Rounding 透過左右平衡來消除這個偏差。

---

### 10-7 ceil() / floor()

`ceil` 天花板、`floor` 地板，光看名字就記得住了。

生活化的例子：計程車跳表。你坐了 5.3 公里，跳表是每 5 公里收一格，結果算 6 格——這就是 `ceil`。

停車費也一樣：進了停車場，停了 1 小時 10 分鐘，大多數停車場「未滿一小時也算一小時」，這也是 `ceil`。

`floor` 則像是「不管賺多少，只整數結算」：你投資賺了 3.9%，結算時顯示 3%——比較傷心，但這就是 `floor`。

負數的時候有點反直覺：`ceil(-3.1)` 是 `-3.0`（往上，靠近 0），`floor(-3.1)` 是 `-4.0`（往下，遠離 0）。只要記住方向永遠是「往正方向 / 往負方向」就不會搞混。

## 第四部分：數學運算方法

### 10-8 一般數學運算（pow、sqrt、cbrt、exp、log）

這幾個方法是「高中數學的 Java 翻譯版」：

- `Math.pow(2, 10)` 就是 2 的 10 次方，等於 1024
- `Math.sqrt(144)` 開平方根，等於 12
- `Math.cbrt(27)` 開立方根，等於 3
- `Math.exp(1)` 就是 e 的 1 次方，回傳自然常數 e
- `Math.log()` 是自然對數（底數 e），`Math.log10()` 是常用對數（底數 10）

一個很實用的小技巧：Java 沒有直接提供 `log₂()`，但你可以用換底公式：

```java
Math.log(8) / Math.log(2)  // 結果 3.0
```

任何底數的對數都可以這樣算。這個在演算法題目裡很常見，記起來值一分錢。

## 第五部分：三角函數

### 10-9 三角函數方法 + 範例

三角函數——很多人看到這個就想起高中的惡夢。

先講一個很重要、很容易踩坑的地方：Java 的三角函數，**參數單位是弧度（radians），不是角度（degrees）**。

你跟它說 90 度？它完全不懂。你要說 `Math.toRadians(90)` 先轉換，才能傳進去。

為什麼要有弧度這個東西？你可以把它想成是 GPS 座標系的基礎語言——所有的球面計算、旋轉矩陣都是弧度在說話。角度只是人類比較習慣的表示方式。

常用方法：
- `Math.toRadians(degrees)` 度轉弧度，進場前必備
- `Math.toDegrees(radians)` 弧度轉度，出場後翻譯
- `Math.sin()`、`Math.cos()`、`Math.tan()` 正弦、餘弦、正切
- 反三角函數 `asin()`、`acos()`、`atan()` 回傳弧度，要再轉回度數

比如說，已知直角三角形對邊 3、斜邊 5，那個角度是多少？

```java
Math.toDegrees(Math.asin(3.0 / 5.0))  // 36.87 度
```

這就是建築師量房子對角線、航海家計算方位角在用的東西。

## 第六部分：Random 類別

### 10-10 Random 類別 + 範例

`Math.random()` 很方便，但有時候不夠用。`java.util.Random` 是它的進化版。

最大的差別是：**Random 可以設種子（seed）**。

什麼叫種子？想像你在農場種田，種下同一批種子，長出來的菜都一樣。Random 也是：相同種子，每次執行程式，亂數序列完全相同。

這在**測試**的時候超級有用。你的程式有個骰子邏輯，想確認特定序列下的行為，就設固定種子，每次跑出來的結果都一樣，bug 跑不掉。

方法很直觀：
- `nextInt(n)` → [0, n) 的整數，直接告訴它你要幾號以內，不用再手動換算
- `nextDouble()` → [0.0, 1.0) 的浮點數，跟 `Math.random()` 一樣
- `nextBoolean()` → 丟銅板，true 或 false 各 50%

---

### Random vs Math.random() 比較

說真的，這兩個選哪個？給你一個懶人決策指南：

**場景一：只需要一個隨機浮點數，或者算個簡單的隨機整數**
→ 用 `Math.random()`，一行搞定，不用 import

**場景二：需要隨機 boolean、需要固定種子重現、或是同一個地方要產很多個亂數**
→ 用 `Random`，功能更完整

有個比喻：`Math.random()` 是便利商店的自動咖啡機，按一下出來；`Random` 是咖啡店的全功能機器，可以調豆子、調濃度、調份量。需求簡單就便利商店，需求複雜就去咖啡店。

## 第七部分：專題——地球兩點距離

### 10-11 Haversine 公式 + 實作

好，最後壓軸登場——Haversine 公式。

這個名字聽起來很嚇人，但概念其實很簡單：**地球是個球，你怎麼量兩個城市之間的距離？**

你不能把地球攤平再用直線量，因為地球是圓的。Haversine 公式是球面幾何的標準解法，把地球假設成一個完美球體（半徑 6371 公里），用球面三角函數計算兩點之間的「大圓距離」。

大圓距離是什麼？就是從地球中心切出去的最短弧線，也是飛機實際飛行的路徑。你有沒有注意過，從台灣飛歐洲的航線，看地圖好像是往北走弧線，而不是直線往西？那就是大圓航線。

這個公式用到了本章幾乎所有的 Math 方法：

- `Math.toRadians()` 把緯度經度轉弧度
- `Math.sin()`、`Math.cos()` 做球面計算
- `Math.sqrt()` 開根號
- `Math.atan2()` 計算圓心角
- `Math.pow()` 求平方

把台北（緯度 25.033、經度 121.565）和東京（緯度 35.689、經度 139.692）的座標代進去，算出來約 **2097.9 公里**。

這個數字跟 Google Maps 查到的非常接近。你剛剛用不到 20 行 Java，重現了 GPS 導航的核心計算。這就是為什麼要學 Math 類別。

## 練習一：樂透號碼產生器

來，動手時間！

第一題是台灣大樂透：從 1 到 49 抽 6 個不重複號碼，排序後印出，再額外抽一個特別號。

核心問題是「不重複」怎麼做？答案是 `ArrayList` + `contains()` 檢查。

每抽一個號碼前，先問 ArrayList：「你裡面有這個數字嗎？」沒有才加進去，有的話就重抽。用 `while (nums.size() < 6)` 跑迴圈，直到湊滿 6 個。

排序用 `Collections.sort()`，一行搞定。

印出時用 `String.format("%02d", n)` 補零到兩位數，這樣 3 會印成 03，看起來才像樂透號碼。

特別號一樣邏輯：抽到數字之後，確認不在前 6 個號碼裡，才算數。

## 練習二：BMI 計算器

第二題是 BMI 計算機，結合 `Math.pow()` 和捨入方法。

公式是 BMI = 體重（kg）除以身高的平方（m²）。

要注意的小地方：身高輸入是公分，要先除以 100.0 換成公尺，而且要除以 `100.0`（有小數點），不能除 `100`，否則整數除法會讓你哭。

取小數一位的技巧：`Math.floor(bmi * 10) / 10.0`——先乘 10 放大，floor 取整，再除回來。

這題有個延伸挑戰很有趣：試試換成 `Math.round(bmi * 10) / 10.0` 或 `Math.rint(bmi * 10) / 10.0`，三種方法在邊界值會有什麼不同？自己跑一下，感受就出來了。

BMI 判斷表很直觀，用 if-else if 串起來就好。
